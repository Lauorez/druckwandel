# E-Rechnung Virtual PDF Printer 0.1.0-beta.1

Erste private Beta für einen interaktiven End-to-End-Test auf Windows 11.

## Voraussetzungen

- Windows 11 24H2 oder neuer, mindestens Build 26100
- x64
- PowerShell als Administrator für das Vertrauen des Development-Zertifikats

## Installation

Die beiden Release-Dateien `CompanionApp_0.1.0.1_x64.msix` und `ERechnung.Dev.cer` in denselben Ordner herunterladen. Anschließend PowerShell als Administrator öffnen:

```powershell
Import-Certificate `
  -FilePath .\ERechnung.Dev.cer `
  -CertStoreLocation Cert:\LocalMachine\TrustedPeople
Add-AppxPackage .\CompanionApp_0.1.0.1_x64.msix
```

Danach sollte die Queue `E-Rechnung` erscheinen:

```powershell
Get-Printer -Name "E-Rechnung"
```

## Erster Test

Notepad öffnen, eine kurze Textseite erstellen und über `Drucken → E-Rechnung` ausgeben. Erwartet werden:

1. kein zusätzlicher Windows-Speichern-unter-Dialog,
2. automatisch erzeugtes lokales PDF,
3. geöffnete Companion-App mit dem richtigen Job,
4. funktionierende Aktionen `Open PDF`, `Open Folder` und `Close`.

Der vollständige Testplan steht in `docs/testing.md`.

## Wichtiger Hinweis

Das Paket ist mit einem selbst signierten Development-Zertifikat versehen. Dieses Zertifikat und die Beta sind ausschließlich für den privaten Test bestimmt und nicht für eine öffentliche oder produktive Distribution geeignet.

Build, Signatur, Paketinhalt, Installation, Queue-Registrierung und Deinstallation wurden automatisiert auf Windows Build 26100 geprüft. Der interaktive Druck- und Companion-Pfad ist der zentrale Gegenstand dieses Betatests.
